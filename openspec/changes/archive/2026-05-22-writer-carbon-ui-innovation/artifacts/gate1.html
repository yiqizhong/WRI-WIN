Primary users

Persona A · Copy reviewer (Morgan)
Designer / content designer · 30–90 min focused sessions
Mental model: inbox → before/after → approve → export
Core friction: Queue buried below setup cards; unclear empty vs. no audit.
Persona B · Platform operator (Alex)
Owns CLI agents + Figma MCP on this machine
Mental model: connections green before review starts
Core friction: Daemon degraded without naming capability; MCP mixed with review UI.

Electron desktop Local daemon Human gate mandatory IBM Carbon brand (fixed)

Core scenarios

  • Figma flow audit: Open project → Sources → start session → Review queue → approve → export
  • Paste / spreadsheet: Sources → paste or import → map columns → session → Review
  • Platform setup: Agents → select provider → Figma OAuth → test read → daemon connected
  • Bulk approval: Review → filter proposed → bulk approve → export
  • Brand voice: Settings → save guidance for active project

Key friction

  • IA Single scroll page hides the approval queue below Figma/setup cards
  • State Project, session, adapter, and daemon health not visible at a glance
  • Ops Connection diagnostics mixed with review content; recovery after daemon restart unclear
  • Density Hero cards and queue compete for attention — no density gradient
  • Errors Critical failures must not use disappearing toasts (restraint L04)

4 · Interaction logic

Navigation

Persistent left sidebar with four items inside ProductChrome (below seed masthead). Active nav uses surface change, not accent color (restraint L01). No hamburger at desktop widths (min 1040px). Default route is Review.

State changes

  • No project: Session actions disabled; Review empty state points to Open project.
  • Project, no session: Review empty state with text links to Sources (no wizard modal).
  • Active session: Review header strip shows project, short session id, source type, status counts.
  • Daemon degraded: Sidebar footer tile shows capability messages from /health + Refresh.
  • Smoke tests: One inline banner region per screen; new result replaces previous (no toast stack).

Errors / empty states

Connection and save failures use persistent inline regions (L04), not toasts. Queue empty after audit: explain filter or prompt Run audit on Review toolbar. Mapping invalid on Sources: inline form error; session not created. No onboarding bubbles or “Pro tip” copy (L06, Quiet Confidence).

Designer input requested: Sidebar nav label — Sources (accurate) vs Figma (familiar)? If Figma, page subtitle must say “Figma, paste, and spreadsheet.”

5 · Key decisions

D1 · Persistent sidebar (4 areas)
30+ min sessions switch context often; scales to Changelog/Reports. Rejected: single-page scroll stack.
D2 · Review is default landing route
Human gate queue is the product core. Rejected: dashboard hero cards (LLM default).
D3 · Session sources on dedicated Sources screen (/figma)
Separates setup from triage (density gradient). Rejected: modal wizard.
D4 · Daemon status in sidebar footer
Persistent diagnostics for operators (L04). Rejected: header badge only.
D5 · Inline banners for smoke / save errors
Critical state must not disappear. Rejected: toast for errors.
D6 · Session context strip on Review header
Project + session + source + counts. Rejected: window title only.
D7 · Open Project stays in global header
High-frequency action. Rejected: bury in Settings.
